# Web Inspiration Notes

External sites are category references only. Do not copy marketplace scripts,
template code, preview text, or project structures into completions.

## Current Corpus

The source corpus is intentionally small: manually curated, owned trailer
samples in `data/synthetic/templates/`, listed directly in
`data/synthetic/manifest.json`.

Keep future additions at the same bar:

- distinct visual niche, not a palette swap
- fast professional pacing with readable secondary text
- multi-scene trailer structure with transitions and final lockup
- broad After Effects API coverage across the curated set
- clean live execution and no obvious layer overlap in manual review

## Reference Signals

- aescripts and Eje in Motion are useful for workflow-script categories such as
  captions, motion trails, loop helpers, grids, path tools, sound markers, and
  procedural visual-effect generators.
- Tuts+/Envato, Motion Array, Mixkit, Aeguys, Storyblocks, and Motionstyles are
  useful for broad template categories such as trailer titles, logo reveals,
  lower thirds, broadcast packs, social promos, media walls, glitch looks, and
  event openers.
- These references can inform prompts, tags, API coverage goals, and review
  criteria, but generated JSX must remain first-party and owned.

## Next Good Additions

Prefer samples that expand API coverage and visual grammar rather than adding
more of the same:

- a marker/audio-driven trailer with beat-synced text and graphics
- a map/data-driven trailer with path reveals and camera travel
- a character-safe social promo using masks, mattes, and precomps
- a broadcast graphics package with lower thirds, scorebug, and transitions
- a dense but readable UI/HUD scene with camera parallax and expressions
- a precomp-heavy science or product explainer that uses mattes and masks

## Manual Review Notes

- 2026-06-10: `product_sequence_launch_trailer.jsx` is kept as an
  asset-backed API coverage checkpoint, but it is not visually accepted as a
  high-quality curated sample yet. Manual review found the generated PNG
